# Organization application operations

Installation and schema ownership are separated. Follow the [canonical release procedure](../../../hrms-documentation/docs/deployment/organization-infrastructure.md) and [phase/cleanup audit](../../../hrms-documentation/docs/deployment/organization-phase-cleanup-audit.md). Production PostgreSQL provisioning is in [hrms-database](../../../hrms-database/provisioning/organization/README.md), ClickHouse schema/TLS/migrations in [hrms-clickhouse](../../../hrms-clickhouse/README.md), Kafka/Connect/topics/ACL operations in [hrms-kafka](../../../hrms-kafka/README.md). No infrastructure installation Compose or production provisioning SQL remains in this service folder.

Application workers remain in [integrations/organization-events](../../integrations/organization-events): strict business/control contracts, independent inbox/history/reporting transactions, capture coordinator, source-only exporter, encrypted archive, persisted accepted-policy retention. Application code owns authorization, event meaning and source receipts; infrastructure retry cannot replace those rules.

Use [independent lifecycle](independent-lifecycle.md), [control history](control-history.md), [source diagnostics](filelog.md) and [capture coverage](heartbeat-coverage.md) for application behavior. Deployment-owned example bindings and OTel/filelog configuration moved to [hrms deployment](../../../hrms-documentation/deploy/hrms/organization). Synthetic-only infrastructure is [deployment acceptance Compose](../../../hrms-documentation/deploy/acceptance/compose.yaml); it is not a production installation.

Independent source business state, command receipts/jobs, operational audit readers and notification/Finance delivery remain required. The obsolete coupled consumer and offline cleanup planner are removed. Use the accepted-policy cleanup CLI only after capture, history, archive, receipt and retention evidence is accepted; no production deletion or global worker stop occurred.

Current local proof is recorded in the dated infrastructure workstream ledgers: all six refreshed event fixtures and 20 files / 55 unit tests pass; two-company PostgreSQL16.15 TLS/CDC/private-proxy and fresh ClickHouse checks pass. All four application images are built and inspected. Final Rust export excludes stale cached executables and the checked runtime libraries resolve. Full application startup, live rollout, browser behavior, HA/restore and complete legacy retirement remain separate acceptance gates.
