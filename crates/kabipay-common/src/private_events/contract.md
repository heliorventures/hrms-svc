# Private events wire and persistence contract v1

Owner: foundation. Shared contract locked 2026-10-19 before implementation.

Wire envelope JSON has exactly: schema_version (1), event_id (UUID, frame event identity), record_id (UUID, original audit/intent identity), tenant_id (UUID), purpose (`audit`, `delivery`, `operator_audit`), source_generation (positive integer at most 9007199254740991), source_kind (bounded ASCII identifier), resource_type (bounded ASCII identifier), resource_id (UUID), occurred_at (UTC RFC3339 with exactly six fractional digits), key_id (bounded ASCII identifier), source_sha256 (lower hex SHA256 of original unmodified UTF8 serialized source bytes), source_size (integer bytes), frame_index (zero based), frame_count (integer), nonce (canonical base64 12 bytes), ciphertext (canonical base64 ciphertext followed by 16 byte GCM tag). AES256-GCM only. Exact payload bytes are framed before encryption, never reserialized for hashing/restore. Maximum source 16MiB, frame 256KiB, 64 frames; empty source rejected. Source kinds preserve unknown legacy kinds when using valid bounded identifier syntax.

AAD is UTF8 `kabipay-private-event-v1` followed by NUL, then length-prefixed UTF8 decimal `<byte_length>:<value>` for fields in this order: schema_version,event_id,record_id,tenant_id,purpose,source_generation,source_kind,resource_type,resource_id,occurred_at,key_id,source_sha256,source_size,frame_index,frame_count. Numeric fields use decimal integers. All immutable fields are authenticated. Nonce/ciphertext are authenticated by GCM. Consumers must compare trusted tenant/purpose and validate all frames/complete hash before accepting a record. Historical exports remain non-executable.

Key file from trusted runtime `KABIPAY_PRIVATE_EVENT_KEYS_FILE`: UTF8 JSON `{ "schema_version":1,"keys":[{"tenant_id":"uuid","purpose":"audit","key_id":"id","key_b64":"base64 32 bytes","active":true}] }`. At most 64KiB/256 keys; unique tenant/purpose/key_id; exactly one active key per configured scope. Old inactive keys remain readable. No fallback keys. Do not log key material or payload. Tests pass keys directly; never mutate environment.

SQL tenant company_event_outbox uses unchanged existing columns id,source_tenant_id,organization_id,event_type,aggregate_type,aggregate_id,aggregate_version,event_envelope,created_at plus event_stream. For private records organization_id=NULL, event_stream=purpose (`operator_audit` is metadata only), event_type=`private.audit.v1` or `private.delivery.v1`, aggregate_type=resource_type, aggregate_id=resource_id, aggregate_version=1, id=event_id, event_envelope=encrypted envelope JSON. Company default stream remains company. Framed inserts use one statement to preserve atomicity on any ConnectionTrait including a transaction/savepoint.

Delivery receipt table `private_delivery_receipt`: tenant_id UUID, intent_id UUID, destination_id UUID, source_kind TEXT, resource_id UUID, intent_hash CHAR(64), destination_version BIGINT, status TEXT DEFAULT 'PENDING', created_at TIMESTAMPTZ, PRIMARY KEY(tenant_id,intent_id,destination_id). Immutable intent stores id/event_type/destination_id/destination_version/source_kind/resource_id/payload/original occurred_at; no arbitrary worker URL/secrets. One source intent per destination. Receipt plus all encrypted outbox frames inserted in one CTE statement; repeated matching identity/hash is idempotent, conflicting hash fails closed. Source_kind values include webhook,finance_confirmation,finance_cancellation. Receipt lease/outcome extension belongs to source adapter.

Audit input fields preserve old record id,tenant_id,user_id,entity_type,entity_id,action,before_state,after_state,ip_address,user_agent,created_at without known-action/entity restrictions. Raw payload contains those exact fields. Audit resource_type is the fixed hint audit_record; original entity_type remains encrypted. Query ports return source unavailability/gaps as errors; the reader owner must implement tenant/purpose scoped pending outbox merge against authenticated capture coverage, with fixed bounded filters. Foundation does not provide an unsafe all-outbox overlay.

Private producer authority: the same CTE obtains private_source_cutover.producer_generation for tenant_id FOR SHARE, then explicitly sets private_delivery_receipt.source_generation. Both audit and delivery first read this generation to encrypt the authenticated head, then their publication CTE locks WHERE producer_generation=expected FOR SHARE. Missing authority or generation rollover prevents receipt/outbox writes. Existing receipts require identical hash/metadata and current generation. PREPARED/FENCED/RETIRED refer legacy source ownership, so no state predicate excludes new private writes. Updating generation is serialized against new intent publication by the authority row lock.
