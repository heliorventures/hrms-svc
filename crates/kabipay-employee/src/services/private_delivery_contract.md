# Source adapter wire v1

Fixed source path: HTTPS POST `/internal/private-events/delivery`. No worker URL, payload, source DSN, client JWT, Finance credential or webhook key occurs in a request. Request size limit 16KiB. JSON envelope: `{ "request": REQUEST, "signature": BASE64URL_NO_PAD_HMAC }`.

REQUEST fields, in exact order for compact UTF8 JSON signing: `version` (1), `tenant_id` UUID, `intent_id` UUID, `destination_id` UUID, `source_generation` integer, `destination_version` integer, `intent_hash` lowercase SHA256, `lease_generation` integer, `request_id` UUID, `issued_at` integer UTC seconds. HMAC-SHA256 signs UTF8 `kabipay-private-delivery-request-v1` + NUL + exact compact ordered JSON. Signatures use canonical unpadded base64url. Clock allowance 60 seconds old, 5 seconds future. Every transport retry signs a fresh time with the same request_id and requested lease_generation.

Reply envelope `{ "response": RESPONSE, "signature": BASE64URL_NO_PAD_HMAC }`. RESPONSE ordered fields: `version`, `tenant_id`, `intent_id`, `destination_id`, `source_generation`, `destination_version`, `intent_hash`, `lease_generation`, `request_id`, `issued_at`, `status`, `outcome_code`, `acknowledgement_id` (UUID or null). Domain `kabipay-private-delivery-response-v1` + NUL. Worker MUST verify every request identity binding, fresh response time and signature before durable outcome acceptance. Actual receipt lease_generation may exceed the request for a status query, so must be adopted only after signature verification.

`lease_generation=0` is a status query only. New execution requires exactly receipt generation + 1 and state PENDING or RETRYABLE. Claim owner is the request UUID. Same claim request never resends. Completed requests return durable receipt. Expired PROCESSING becomes UNCERTAIN and is never automatically reexecuted. DELIVERED/DISABLED/NO_DESTINATION/PERMANENT/UNCERTAIN are durable terminal outcomes. HTTP 2xx remains at least once: a crash after receiver success before durable receipt leaves UNCERTAIN. RETRYABLE owns only a safe presend failure or definite receiver retry response, never an ambiguous timeout.

Trusted source config `KABIPAY_PRIVATE_DELIVERY_ADAPTER_FILE` is bounded 64KiB JSON `{ "schema_version":1,"bindings":[{"tenant_id":"uuid","source_generation":1,"key_b64":"base64 32+ bytes","allowed_webhook_hosts":["hooks.example.com"],"webhook_keys":[{"key_id":"configured-reference","key_b64":"base64 32+ bytes"}]}]}`. One binding per tenant; no default secret. Shared worker receives only the tenant proof key and fixed source endpoint, never webhook_keys. Source generation must additionally match database authority and immutable receipt generation.

Webhook destinations are source-configured subscription UUIDs with immutable destination_version and signing_key_ref. Source decrypts immutable original intent; no request payload can replace it. Every DNS address must be public, exact host must be allowlisted; DNS is pinned for this request, HTTPS443 only, redirects/proxies disabled, body/response/time bounded. Signature preserves v1 `timestamp.body` HMAC and adds stable `X-KabiPay-Delivery-Id` / `Idempotency-Key`. No signing key can be recovered from a legacy subscription hash.

Finance destination UUID is `00000000-0000-4000-8000-000000000002`, version1. Intent id is terminal operation UUID; resource id is the same operation. Event kind and source_kind must agree with the authoritative terminal Employee operation. Adapter freshly invokes existing signed Employee-to-Payroll transport, preserves authoritative Payroll readback, and accepts only matching operation/state receipts.
